펼치기 ▾

AI 에이전트 시대에 모든 직무는 세 가지 층으로 재분류됩니다.
어떤 태스크를 에이전트에게 맡기고, 인간은 어떤 판단에 집중할 것인가를 정의하는 프레임워크입니다.

1
에이전트 자동 실행
규칙이 명확하고 패턴이 반복되는 태스크. 에이전트가 기준에 따라 자동으로 처리합니다.
예: 이력서 1차 스크리닝, 면접 일정 자동 조율, 데이터 수집·정리, 정기 리포트 생성
2
에이전트 + 인간 협력
에이전트가 초안·분석을 제시하고, 인간이 맥락을 보완해 최종 판단하는 태스크.
예: 채용 공고 초안 작성, 후보자 평가 리포트 생성, 면접 질문 세트 제안, 보상 시뮬레이션
3
인간 전담 판단
이해관계자의 감정, 조직 정치, 책임 귀속이 개입되어 반드시 사람이 담당해야 하는 판단.
예: 최종 합격 결정, 연봉 협상, 채용 전략 수립, 조직 문화 적합성 판단
💬 핵심 원칙: 직무의 가치는 "무엇을 하는가"가 아닌 "어떤 판단을 책임지는가"로 정의됩니다. Layer 3에 입력하는 내용이 이 직무의 본질입니다.
